# openpulse
View OpenWRT status, at a glance

This app is on both macOS and iOS.

# Prequistes
Coming soon

# macOS
You can download the macOS prebuilt binary from releases. They are NOT signed, and you have to trust the app. If you do not know how to do this, you are probably NOT the target audience for this app.
Alternatively, you can build from source using xcode.

# iOS/iPadOS
I do not have an apple developer license, therefore I cannot disturbute using app store. The app is sandboxed, however, and is available to install using an ipa file. You can sideload this using altstore or other methods, however I have a direct altstore source (coming soon) which enables easier installation.

# Other notes
The app is sandboxed on both versions.
The app assumes your router ip is at 192.168.1.1.
